## About A-Mills HVAC

The **A-Mills HVAC website** is a responsive lead-generation and service management platform built with modern PHP and front-end technologies.  
It was engineered for **A-Mills Heating and Cooling (Kansas City, MO)** to provide customers with fast access to HVAC consultation requests, repair scheduling, and contact services.  

This project showcases a **Laravel + Livewire + TailwindCSS** tech stack, running on an **OVHCloud Debian 11** dedicated server managed through **Plesk**.  
Deployed via **Git-based CI/CD** and **SSH automation**, it integrates SEO optimization, caching, and secure HTTPS delivery with automatic certificate renewal.

---

## Core Technologies

- **Laravel 10** – Core application framework (MVC architecture)
- **Livewire** – Dynamic, reactive UI components without JavaScript overhead
- **Blade** – Templating engine for modular, reusable layouts
- **TailwindCSS** – Utility-first CSS framework for responsive design
- **MySQL** – Primary relational database for contact forms and lead storage
- **PHPMailer** – Secure email transport for consultation and service forms
- **Plesk + CloudPanel** – Server management, SSL, DNS, and deployment
- **SEO Optimization** – Structured metadata, sitemaps, and schema markup for local search
- **Varnish Cache + HTTPS** – Performance optimization and secure delivery

---

## Key Features

- **Service Request System:** Simple, secure HVAC consultation and repair request form  
- **Responsive Design:** Optimized for mobile, tablet, and desktop  
- **Admin Dashboard:** Built for internal tracking and reporting (future module)  
- **SEO/Schema Ready:** Local business structured data for better visibility  
- **Fast Deployment:** Managed via Git with automated Plesk deployment  
- **Secure Configuration:** Hardened HTTPS, firewall rules, and fail2ban integration

## Learning Resources

This project follows Laravel’s best practices for:
- Clean MVC architecture and modular component structure
- Separation of concerns between UI (Blade/Livewire) and logic
- Database migrations and Eloquent ORM relationships
- Secure validation and sanitization for all user inputs
